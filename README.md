# Atandra Bharati

Deep Learning Research Engineer building and evaluating AI systems from scratch in PyTorch, with a focus on efficient language models, generative vision, and research tooling.

I work at the boundary of model architecture and systems constraints: memory-aware attention, mixture-of-experts training, state-space models, diffusion pipelines, and reproducible experiment infrastructure.

## Selected work

- [HyMo](https://github.com/atandra2000/HyMo) — hybrid language-model research combining recurrent and attention-based components.
- [FusionLLM](https://github.com/atandra2000/FusionLLM) — hybrid LLM pre-training framework integrating latent attention, gated delta networks, mixture-of-experts, and multi-token prediction.
- [GPT-OSS-Lite](https://github.com/atandra2000/GPT-OSS-Lite) — long-context mixture-of-experts language-model experiments.
- [StableDiffusion](https://github.com/atandra2000/StableDiffusion) — from-scratch diffusion-model training work.
- [EE1101](https://github.com/atandra2000/EE1101) — offline-first interactive textbook for Electronic Systems and Circuits.
